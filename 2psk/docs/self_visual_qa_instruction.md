# 自检指令：2PSK MATLAB 图像质量检查

每次修改 MATLAB 绘图代码并运行 `run_all.m` 后，必须按本文件逐项检查。目标是保证报告和 PPT 中的图清楚、正常、美观，不能出现箭头重叠、文字挤压、图例遮挡、异常空白或布局错乱。

## 运行顺序

1. 清理旧输出图，避免误看旧版本。
2. 运行 MATLAB：

```matlab
cd('C:\Users\19571\Desktop\研讨\通信原理研讨\topic2_2psk_matlab')
run_all
```

3. 确认 MATLAB 正常结束。
4. 确认 `outputs/figures` 中至少有以下 8 张 PNG：
   - `00_system_block.png`
   - `00_program_flow.png`
   - `01_2psk_waveform.png`
   - `02_2psk_spectrum.png`
   - `03_coherent_receiver.png`
   - `04_signal_space_noise.png`
   - `05_ber_curve.png`
   - `06_phase_ambiguity_ber.png`
   - `07_phase_decision_demo.png`
5. 生成并打开 `contact_sheet.png` 做总览检查。
6. 对重点图单独打开原图检查，不能只看缩略图。

## 总体图像质量标准

- 标题完整、居中、没有被裁切。
- 坐标轴标签完整，没有乱码、缺字、被裁切。
- 图例不遮挡主要曲线或关键数据点。
- 注释文字不压住曲线、散点、坐标轴或其他文字。
- 子图之间间距自然，没有明显挤压或过大空白。
- 同一类图的颜色风格一致：蓝色用于主曲线，红色/橙色用于警示或相位误差，青色用于正类信号。
- 图中说明应短而清楚，不堆长句。
- 图中不允许出现倾斜或旋转文字；所有标题、标签、注释、图例必须水平放置。
- 图中不允许使用倾斜摆放的图片、方框或流程元素。
- 报告用图优先保证可读性，不追求复杂装饰。

## 箭头与流程图专项标准

### `00_system_block.png`

- 箭头必须从左到右，方向一致。
- 箭头不能压住方框边界或文字。
- 箭头之间不能重叠。
- 每个功能块文字必须完整可读。
- 方框宽度和间距应均匀。
- 底部核心链路说明不能和主体框图重叠。

### `00_program_flow.png`

- 箭头必须在上下两个步骤之间居中。
- 箭头不能穿过步骤文字。
- 每个步骤框大小一致或视觉上接近一致。
- 不能出现某一步被挤出画布。

## 各图单独检查点

### `01_2psk_waveform.png`

- 三个子图纵向排列正常。
- bit、极性基带、通带信号都完整显示。
- 横轴时间范围一致。
- 通带波形不能糊成实心块到无法理解；若过密，需要减少显示 bit 数或降低载波频率显示密度。

### `02_2psk_spectrum.png`

- 频谱主峰位于 `±f_c` 附近。
- `f_c` 和 `-f_c` 标签不能贴边或遮挡主峰。
- 原始频谱和趋势线要能区分。
- 旁瓣可见，但不能因线条过密导致整图发黑。

### `03_coherent_receiver.png`

- 发送信号、接收信号、相关器输出三部分完整。
- 判决门限标签不能遮挡关键 stem 点。
- 接收信号幅度范围要合理，不能过度裁切。

### `04_signal_space_noise.png`

- 必须是一行三图或明确居中的三图布局。
- 不能出现右下角大面积空白。
- `s_0`、`s_1`、门限 0 标签不能互相遮挡。
- 三个信噪比图的横轴范围一致，便于比较。

### `05_ber_curve.png`

- 仿真 BER 和理论 BER 都可见。
- 图例不能遮挡曲线下降段。
- y 轴必须为对数坐标。
- 若高信噪比出现仿真 BER 为 0，图中可以用绘图下限显示，但报告文字必须解释这是有限样本效应。

### `06_phase_ambiguity_ber.png`

- 90° 标注不能压住曲线、数据点或图例。
- 图例不能遮挡曲线主体。
- 曲线应体现 0° 到 180° 误码率升高趋势。
- y 轴必须为对数坐标。

### `07_phase_decision_demo.png`

- 曲线区和卡片区不能互相覆盖。
- 90°、180° 标签不能贴边。
- 三个卡片大小一致，间距均匀。
- 底部结论不能被裁切。

## 代码审查标准

- `checkcode` 不应报告明显问题。
- BER 基带模型必须使用 `±sqrt(cfg.Eb)`，不能一边固定 `±1` 一边用 `cfg.Eb` 缩放噪声。
- 所有图保存后应关闭 figure，避免 MATLAB 图形窗口堆积。
- 默认只保存 PNG；如需 `.fig`，通过 `cfg.saveFigFiles=true` 开启。
- 新增图必须加入 README 和本自检清单。

## 不合格时的处理

- 不要手工改图片。
- 必须修改 MATLAB 源码后重新运行 `run_all.m`。
- 重新生成 `contact_sheet.png`。
- 再次逐项检查，直到所有图合格。
